# Product Vision

## Идея

Astrology — онлайн-сервис для:

- построения натальной карты
- персональных астрологических прогнозов
- раскладов Таро

## Первая продуктовая цель

Сделать MVP, в котором пользователь может:

1. зайти на красивый landing
2. создать профиль рождения
3. получить базовый астрологический результат
4. попробовать Таро-расклад
5. позже перейти на платные персонализированные сценарии

## Приоритеты

### P0
- структура проекта
- landing
- базовый API
- модуль birth profile
- health endpoints

### P1
- natal chart workflow
- tarot workflow
- auth

### P2
- subscriptions
- billing
- admin panel
